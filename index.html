What's new

    How to install

    1. Tap Download for Android above and wait for the download to finish.
    2. Open the downloaded file, ProjectARISE.apk (from the notification, or from Files › Downloads).
    3. If your phone asks, allow your browser or Files app to install unknown apps, then go back.
    4. Tap Install. If Google Play Protect warns about an unknown app, tap More details › Install anyway.
    5. Open Project ARISE and sign in with the ID and password your adviser or the ALS coordinator gave you.

    Updating

    When there is a new version, download it from this page and install it the same way. It installs over the old one; your account and records stay.

    When the school requires a new version, the app shows an Update Project ARISE screen with a button that opens this page. An older app cannot load or save anything until it is updated.
